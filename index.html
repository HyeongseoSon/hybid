▣ 시스템 개요 및 사용법

1. 과제 개요

과제주제 : 나라장터 입찰공고정보를 이용한 정보통신공사업 적격심사 참가자격 자동판정 및 지역제한 필터링 서비스
과제개요 : 조달청 나라장터 OpenAPI(입찰공고정보서비스)로 공사·용역·물품 입찰공고를 실시간 수집하고, 자사(한영정보통신)의 시공능력액·3년실적·보유업종·본사소재지를 기준으로 참가가능 공고만 자동 선별하여 담당자와 선임이 한 화면에서 검토·분담할 수 있도록 제공
관련업무 : 입찰공고 검색·참가자격 검토 및 투찰 의사결정 지원

2. 활용 데이터

· 조달청_나라장터 입찰공고정보서비스 (data.go.kr 15129394) — REST / JSON
· End Point : https://apis.data.go.kr/1230000/ad/BidPublicInfoService02
· 사용 오퍼레이션
  - getBidPblancListInfoCnstwkPPSSrch 나라장터검색조건에 의한 입찰공고공사조회
  - getBidPblancListInfoServcPPSSrch 용역조회
  - getBidPblancListInfoThngPPSSrch 물품조회
  - getBidPblancListInfoPrtcptPsblRgn 참가가능지역정보조회
  - getBidPblancListInfoLicenseLimit 면허제한정보조회

3. 사용법 및 활용 시나리오

① 설정·수집에서 인증키 입력 → 조회기간(최대 7일)·업무구분 선택 → [실시간 수집 및 적격판정 실행]
② 공고목록에서 판정결과(적격/조건부/부적격)·지역·금액으로 필터링
③ 행 클릭 → 적격판정 탭에서 5개 항목별 판정 근거 확인 → 나라장터 원문 공고 열람
④ 통계에서 금액구간·기관별 분포 확인 후 담당자 분담
⑤ [CSV 내보내기]로 검토결과를 선임과 공유

4. 기술 구성

· 빌드 프레임워크 없음 — HTML + CSS + Vanilla JS 단일 파일(index.html)
· 모든 연산(판정·집계·필터)은 클라이언트 PC 내부에서 수행 — 서버 전송 없음
· 인증키는 브라우저 localStorage에만 저장 — 외부 유출 없음
· 배포 : GitHub Pages (정적 호스팅)
